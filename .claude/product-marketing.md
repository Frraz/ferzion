## PÚBLICO-ALVO (ICP)

**Perfil primário:**
- Donos e gestores de empresas do agronegócio, logística e gestão operacional
- Operações com 5–200 colaboradores
- Empresas que ainda usam planilhas Excel para controles críticos (financeiro, estoque, RH, produção)
- Gestores que percebem que a planilha chegou no limite mas não sabem exatamente o que vem depois
- Perfil técnico baixo a médio — precisam de alguém que entenda o negócio deles, não só o código

**Perfil secundário:**
- Consultores técnicos (agronegócio, pecuária, confinamento) que precisam de ferramentas para o serviço que prestam a clientes
- Profissionais autônomos e pequenas empresas que precisam de presença digital profissional (landing pages)

**Dores principais:**
1. Planilhas que ninguém controla — versões desatualizadas, acesso restrito, fórmulas frágeis
2. Dados espalhados em WhatsApp e e-mail — sem rastreabilidade
3. Retrabalho invisível — horas refazendo o que já foi feito porque não há registro
4. Decisões sem dados — operação gerida na intuição, sem visibilidade real
5. Risco operacional silencioso — cobranças erradas, folha com cálculo manual, estoque sem controle

**Objeções comuns:**
- "É caro demais para o meu tamanho"
- "Vai demorar muito para estar pronto"
- "Vou depender da empresa para sempre"
- "Minha equipe não vai saber usar"
- "Não sei se realmente preciso disso agora"

## CASOS REAIS (PROVA SOCIAL)

### 1. Romaneios de Madeira *(primeiro sistema — alavancou dois contratos seguintes)*
- **Problema:** Controle financeiro em planilha com dupla entrada manual, fórmulas frágeis, versões desatualizadas. Cobranças incorretas eram rotina.
- **Solução:** Sistema com saldo de clientes calculado automaticamente por histórico completo. Sem ajuste manual, sem fórmula que quebra. Cubagem de toras calculada pelo sistema.
- **Resultado:** Primeiro sistema de uma relação que gerou três contratos com o mesmo grupo familiar.
- **Stack:** Django · Python · PostgreSQL · Bootstrap 5 · WeasyPrint

### 2. Rebanho *(segundo sistema do mesmo cliente)*
- **Problema:** 10 fazendas, 8.000+ animais gerenciados por pasta Excel com dezenas de abas. Acesso restrito a uma pessoa. Sem rastreabilidade.
- **Solução:** Plataforma centralizada com padrão Ledger (dados imutáveis), 5 usuários com acesso controlado, relatórios automáticos, visão consolidada de todas as fazendas.
- **Resultado:** Operação centralizada. Cliente voltou para contratar o terceiro sistema.
- **Stack:** Django · PostgreSQL · Redis · Docker · TailwindCSS · HTMX · Alpine.js

### 3. Conftech *(consultores profissionais de confinamento bovino)*
- **Problema:** Consultores sem base de dados estruturada para registrar operações de múltiplos clientes e gerar métricas confiáveis.
- **Solução:** Sistema web com API REST nativa para integração direta com Power BI via token Bearer. Sem exportação manual. Dashboards com GMD, custo por cabeça, projeção de venda.
- **Resultado:** Em produção para dois grupos de consultores de confinamento profissionais.
- **Stack:** Django 5.2 · PostgreSQL · Gunicorn · Render

### 4. Sistema RH *(terceiro sistema do mesmo cliente — o mais técnico)*
- **Problema:** Folha de pagamento em planilha que não cobria todas as rubricas, tabelas de INSS desatualizadas, rescisão feita na estimativa.
- **Solução:** Engine de cálculo própria com 20 rubricas, tabelas legais de INSS e IRRF no banco (atualizáveis sem redeploy), fechamento imutável com hash SHA-256, rescisão CLT completa com memória de cálculo.
- **Resultado:** Em produção em rh.ferzion.com.br. Terceiro sistema consecutivo do mesmo cliente.
- **Stack:** Django 5.0 · PostgreSQL 16 · Redis · Celery · Docker · HTMX · TailwindCSS

### 5. Landing pages e sites institucionais
- **Segmentos atendidos:** empresa de software, portfólio de programador, fisioterapeuta, clínica odontológica
- **Processo:** briefing estruturado → identidade visual sob medida → código do zero → entregue no ar com hospedagem
- **Diferencial:** cada página construída do zero, sem template, com identidade do cliente
